# laboratorio-programacion-ii
Página web sobre el universo de Warhammer 40,000 hecha con HTML y CSS, con un formulario de registro conectado a una base de datos SQLite mediante Flask (Python). Los registros se guardan en warhammer.db y se pueden ver en /registros. Se ejecuta con python app.py. Proyecto del Laboratorio 01 del curso de Programación II.
